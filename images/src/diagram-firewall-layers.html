Layers in front of a public box

Each layer assumes the one outside it will fail sometimes.
🌍 Internet: scanners, password guessers, curious visitors
1 · Host firewall: default drop (IPv4 + IPv6)Open: 22, 80, 443 (+ mail ports on a mail host). Allowed: ICMP/ICMPv6, VPN interface. Panel ports from admin IPs only. Applied with a 5-minute dead-man undo.
2 · fail2ban on every login doorsshd (journalmatch ssh.service!) · SMTP AUTH · IMAP/POP · panel · wp-login/xmlrpc/lost-password. Incremental bans up to 1 week.
3 · ServicesKeys-only SSH · panels with 2FA · web server refuses .bak/.sql/.env/.git · unused services off · internals bound to 127.0.0.1 or VPN
4 · Data & secretsOne 600 file per secret · /root 700 · nothing in web roots or /tmp · transcripts scrubbed
👁️ Daily sweep watches all four layersMessages the owner only when something changed.
